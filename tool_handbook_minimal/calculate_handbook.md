# Policy: calculate

## Conditions for Use
- A calculation is required for baggage fees, travel insurance, compensation, price differences, refunds, or payment differences
- All required input values are confirmed and available
- All relevant policy rules and eligibility criteria (e.g., membership level, payment method, booking status, baggage allowance, compensation eligibility) are satisfied
- Calculation is explicitly or implicitly required for the action or workflow
- User has explicitly confirmed the action if it updates a booking or reservation

## Refusal Conditions
- Required input values are missing or unconfirmed
- Policy rules for the requested action are not met (e.g., baggage addition not allowed, refund not permitted, payment method not refundable)
- User is not eligible for the requested calculation (e.g., compensation, refund, baggage addition)
- Compensation calculation is requested but user is ineligible
- Calculation is not required for the action or workflow

## Critical Reminders
- Always check and confirm membership level, payment method eligibility, and booking/reservation status before calculating
- Use only user-provided or tool-available data for calculations
- Do not calculate compensation unless user explicitly requests it and is eligible
- Zero-result calculations are allowed for baggage or insurance if policy permits, but not for compensation if user is ineligible
- Do not round or estimate results unless specified by policy
